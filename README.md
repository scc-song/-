
# ResumeAuto · 简历分析 + 岗位匹配投递助手

🎯 **给大学生求职者的一站式新能源岗位投递工具**

上传你的 Word 简历，系统自动分析专业背景、证书和经历，帮你匹配光伏 / 风电 / 储能 / 电气等新能源方向岗位，并一键生成 BOSS直聘、猎聘、智联招聘等主流平台的投递搜索链接。

---

## ✨ 主要功能

- **📄 简历本地解析**：上传 `.docx` 格式简历，浏览器自动提取文本
- **🔍 智能方向匹配**：根据你的专业、证书、经历，自动推荐对口岗位关键词
- **🔗 六大平台直达**：为 BOSS直聘、猎聘、智联招聘、前程无忧、拉勾、实习僧生成已填好关键词的搜索链接
- **📊 实时岗位补充**：内置新能源 / 国企央企真实岗位数据
- **📝 反馈驱动优化**：标记投递 / 已读 / 邀约 / 拒绝状态，系统据此生成下一轮简历优化建议
- **🔒 隐私安全**：所有解析都在浏览器本地完成，简历内容不会上传到服务器

---

## 🚀 使用方法

1. 打开网站：https://scc-song.github.io/-/  
2. 点击「上传简历」，选择你的 `.docx` 简历
3. 系统自动生成你的简历画像，并更新右侧平台推荐关键词
4. 点击任意平台的蓝色关键词按钮，跳转该平台搜索页
5. 登录招聘平台账号，直接投递匹配岗位
6. 返回本页，在职位卡片标记投递结果，持续优化简历

## 🛠 技术说明

- 纯静态单页应用，无后端服务器
- 使用 `JSZip` + `docx.js` 在浏览器端解析和生成 Word 文档
- 招聘数据与页面内嵌，无需数据库
- 投递反馈状态保存在浏览器本地存储中

---

## 📮 提示

- 请使用 `.docx` 格式的 Word 简历
- 如简历中缺少电气/储能/光伏等关键词，可在「简历画像」区手动补充后生成优化版简历
- 建议使用 Chrome / Edge / Safari 等主流浏览器访问
